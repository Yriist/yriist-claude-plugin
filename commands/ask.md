Передай вопрос ИИ-юристу ЮрИИста инструментом `ask_yriist`:

$ARGUMENTS


- Вопрос пустой: спроси пользователя, что он хочет узнать, и не вызывай инструмент.
- Собери в `question` все факты из разговора: даты, суммы, стороны, регион. Без них ответ получится общим.
- Файлы к вопросу. Файл уже лежит в ЮрИИсте: возьми `file_id` из `files_list` и передай в `file_ids` (до 10). Локальный файл сначала загрузи по навыку `yriist:yriist-files`. Вопрос о документе из «Документов» или просьба его поправить: передай `document_id`. Вопрос по делу из «Дел»: `project_id` (только для нового чата).
- `audience: lawyer` даст ответ для юриста с нормами и практикой, `general` объяснит простым языком. Не знаешь, кто спрашивает: не передавай, ЮрИИст возьмёт настройку из профиля.
- Передай `wait_seconds: 100`. Готовый ответ придёт сразу, длинный не задержит сессию.
- Вопрос расходует одно сообщение тарифа. **Не вызывай `ask_yriist` повторно с тем же вопросом** после `status: running`, тайм-аута или ошибки сети: ЮрИИст дописывает ответ на сервере, сообщение уже списано. Пока ответ готовится, ЮрИИст не примет в этом чате новый вопрос. Уточнение задавай в том же чате с `chat_id`.
- `status: running`: ответ ещё готовится. Скажи об этом пользователю, дай ссылку на чат и прочитай `chat_read` с `chat_id` из ответа один раз, когда пользователь вернётся или ты закончишь другую работу. Не опрашивай `chat_read` подряд. Пользователь передумал или задал вопрос не так: `chat_stop` остановит ответ (Claude Code спросит разрешение), написанная часть останется в чате.
- Вызов оборвался, `chat_id` нет: вызови `chats_list` с `limit: 3`, найди самый новый чат с этим вопросом и прочитай его `chat_read`. Не нашёл: скажи, что ответ появится в приложении ЮрИИста. Заново спрашивай только с согласия пользователя.
- `chat_read` отдаёт последние сообщения. Начало длинного чата читай с `from_message`.
- Перескажи ответ без искажений, сохрани номера источников [n] и дай ссылку на чат. Документы из ответа (`document_id`) открывает `/yriist:documents`.
