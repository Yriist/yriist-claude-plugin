# ЮрИИст для Claude Code

**ИИ-юрист по праву РФ прямо в терминале.** Плагин подключает к Claude Code
[ЮрИИст](https://yriist.ru): судебная практика, нормы со сверкой, контрагенты,
расчёты неустойки, госпошлины и сроков, ваши чаты, документы и «Сроки и дела».

## Установка

Нужен аккаунт [ЮрИИста](https://app.yriist.ru).

1. В сессии Claude Code:

   ```
   /plugin install yriist --marketplace Yriist/yriist-claude-plugin
   ```

   Claude Code спросит, добавить ли источник (`y`), и предложит область
   установки.

2. Войдите: `/mcp` → **yriist** → **Authenticate**. Откроется окно ЮрИИста —
   разрешите доступ.

3. Проверьте: `/yriist:status`.

<details>
<summary>Из оболочки или из приложения Claude для компьютера</summary>

```sh
claude plugin install yriist --marketplace Yriist/yriist-claude-plugin
```

В приложении: «+» у поля ввода → Plugins → Add marketplace
`Yriist/yriist-claude-plugin` → Add plugin.

</details>

<details>
<summary>Вход по личному токену вместо OAuth</summary>

Создайте токен в [Аккаунт → Подключения](https://app.yriist.ru/account/connections)
и положите его в файл:

```sh
mkdir -p ~/.config/yriist && (umask 077 && printf '%s\n' 'yrp_…' > ~/.config/yriist/token)
```

Скрипт `scripts/mcp-headers.sh` добавит заголовок `Authorization` при
подключении. Пока файл есть, OAuth для этого сервера не используется; чтобы
вернуться к OAuth, удалите файл. Переменная окружения не годится: Claude Code
не передаёт скрипту заголовков переменные с секретами (`*_TOKEN`).

</details>

## Команды

| Команда | Что делает |
| --- | --- |
| `/yriist:ask <вопрос>` | вопрос ИИ-юристу ЮрИИста; ответ сохраняется чатом в приложении |
| `/yriist:research <вопрос>` | исследование: нормы, практика, расчёты, вывод |
| `/yriist:court <вопрос или № дела>` | судебная практика или карточка дела |
| `/yriist:law <ст. 333 ГК РФ>` | текст нормы со сверкой и проверкой актуальности |
| `/yriist:claim <ситуация>` | претензия или иск → «Документы» ЮрИИста |
| `/yriist:contract <id или файл>` | проверка договора на риски |
| `/yriist:company <ИНН>` | проверка контрагента |
| `/yriist:deadlines [событие]` | сроки и дела: что горит, новый срок |
| `/yriist:calc <что посчитать>` | неустойка, госпошлина, срок |
| `/yriist:status` | тариф и остаток сообщений |
| `/yriist-panel` | панель ЮрИИста |

> [!IMPORTANT]
> `/yriist:ask` расходует одно сообщение вашего тарифа ЮрИИста. Остальные
> команды работают через инструменты поиска и расчётов.

> [!NOTE]
> Команды заранее разрешают только чтение и расчёты. Всё, что меняет ваши
> данные — сохранить срок, создать документ, поставить дело на мониторинг, —
> Claude Code подтверждает у вас обычным запросом разрешения.

### Интерфейс Claude Code

Плагин добавляет в сам Claude Code:

- **строку состояния** — тариф, остаток сообщений, горящие сроки:

  ```
  ЮрИИст · Профи · 42 сообщения · сроков ≤3 дн.: 1
  ```

- **полосу над полем ввода**, когда срок просрочен или наступает в ближайшие
  3 дня; «Скрыть» убирает её до следующего срочного срока:

  ```
  ЮрИИст · срок через 2 дня: Апелляционная жалоба (12.11.2026)   [Сроки] [Скрыть]
  ```

- **панель `/yriist-panel`** — аккаунт, сроки с кнопкой «Готово», последние
  чаты (клик подтягивает чат в разговор), «Спросить ИИ-юриста»;
- **подпись под каждым вызовом инструмента** — «ЮрИИст · Судебная практика».

## Права

При входе ЮрИИст спрашивает, что разрешить. Отозвать доступ — в
[Аккаунт → Подключения](https://app.yriist.ru/account/connections).

| Право | Что даёт |
| --- | --- |
| `yriist:research` | практика, нормы, контрагенты, расчёты, поиск |
| `yriist:read` | ваши чаты, документы, шаблоны, сроки, дела, аккаунт |
| `yriist:write` | создать документ, сохранить срок, мониторинг дела, память |
| `yriist:agent` | `ask_yriist` (расходует сообщение тарифа) |

## Если что-то не так

| Симптом | Что сделать |
| --- | --- |
| Строка состояния «ЮрИИст: войдите — /mcp» | `/mcp` → yriist → Authenticate |
| Панель: «Сервер yriist выключен» | включите сервер в `/mcp` |
| Панель: «ЮрИИст недоступен» | проверьте сеть; состояние сервера — в `/mcp` |
| Токен в файле, а сервер просит войти | токен удалён или истёк: создайте новый или удалите файл и войдите через OAuth |
| Нет `ask_yriist` или действий | при входе не выдано право: отключите приложение в «Подключениях» и войдите снова |
| После смены способа входа сервер не подключается | перезапустите Claude Code |
