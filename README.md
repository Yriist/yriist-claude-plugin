# ЮрИИст для Claude Code

**ИИ-юрист по праву РФ в терминале.** Плагин подключает к Claude Code
[ЮрИИст](https://yriist.ru): судебную практику, нормы со сверкой, контрагентов,
расчёты неустойки, госпошлины и сроков. Из терминала вы работаете и со своими
данными в ЮрИИсте: чатами, «Делами», файлами, документами, сроками, памятью.

## Установка

Нужен аккаунт [ЮрИИста](https://app.yriist.ru).

1. В сессии Claude Code:

   ```
   /plugin install yriist --marketplace Yriist/yriist-claude-plugin
   ```

   Claude Code спросит, добавить ли источник (`y`), и предложит область
   установки.

2. Войдите: `/mcp` → **yriist** → **Authenticate**. В окне ЮрИИста
   разрешите доступ.

3. Проверьте: `/yriist:status`.

<details>
<summary>Из оболочки или из приложения Claude для компьютера</summary>

```sh
claude plugin install yriist --marketplace Yriist/yriist-claude-plugin
```

В приложении: «+» у поля ввода → Plugins → Add marketplace
`Yriist/yriist-claude-plugin` → Add plugin.

</details>

<details>
<summary>Вход по личному токену вместо OAuth</summary>

Создайте токен в [Аккаунт → Подключения](https://app.yriist.ru/account/connections)
и положите его в файл:

```sh
mkdir -p ~/.config/yriist && (umask 077 && printf '%s\n' 'yrp_…' > ~/.config/yriist/token)
```

Скрипт `scripts/mcp-headers.sh` добавит заголовок `Authorization` при
подключении. Пока файл лежит на месте, Claude Code не входит в этот сервер
через OAuth; удалите файл, чтобы вернуться к OAuth. Переменная окружения не
подойдёт: Claude Code не передаёт скрипту заголовков переменные с секретами
(`*_TOKEN`).

</details>

## Команды

**Вопросы и исследование**

| Команда | Что делает |
| --- | --- |
| `/yriist:ask <вопрос> [файл]` | вопрос ИИ-юристу ЮрИИста; ответ сохранится чатом в приложении |
| `/yriist:research <вопрос>` | исследование: нормы, практика, расчёты, вывод |
| `/yriist:court <вопрос или № дела>` | судебная практика |
| `/yriist:law <ст. 333 ГК РФ>` | текст нормы со сверкой и проверкой актуальности |
| `/yriist:verify <файл или текст>` | проверка черновика: нормы, ссылки, цифры, сроки |
| `/yriist:company <ИНН>` | проверка контрагента |
| `/yriist:requisites <суд, банк, ИФНС>` | реквизиты |
| `/yriist:calc <что посчитать>` | неустойка, госпошлина, срок |

**Документы и файлы**

| Команда | Что делает |
| --- | --- |
| `/yriist:contract <файл или документ>` | проверка договора на риски, в том числе из DOCX и скана |
| `/yriist:claim <ситуация>` | претензия или иск в «Документы» ЮрИИста |
| `/yriist:documents [название]` | ваши документы: прочитать, поправить, скачать DOCX или PDF |
| `/yriist:templates <что нужно>` | 230+ шаблонов ЮрИИста, копия в «Документы» |
| `/yriist:file <путь>` | загрузить файл в ЮрИИст и прочитать его текст |
| `/yriist:anonymize <файл или текст>` | убрать персональные данные |
| `/yriist:review <файлы>` | табличный анализ многих документов |

**Дела, сроки, аккаунт**

| Команда | Что делает |
| --- | --- |
| `/yriist:projects [дело]` | «Дела»: чаты, файлы, документы и сроки клиента |
| `/yriist:case <№ дела>` | судебное дело: карточка, движение, мониторинг |
| `/yriist:deadlines [событие]` | сроки: что горит, новый срок, отметка «выполнен» |
| `/yriist:chats [запрос]` | найти и прочитать прошлый чат |
| `/yriist:memory` | что ЮрИИст помнит, запомнить, забыть |
| `/yriist:status` | тариф, сколько использовано, что открыто |
| `/yriist-panel` | панель ЮрИИста |

> [!IMPORTANT]
> `/yriist:ask` расходует одно сообщение вашего тарифа ЮрИИста, поэтому её
> запускаете только вы: Claude сам эту команду не вызывает. Остальные команды
> ищут и считают, сообщений они не тратят. Ответ ИИ-юриста готовится до
> нескольких минут. Вызов оборвался: команда найдёт чат через `chats_list` и
> не задаст вопрос повторно.

> [!NOTE]
> Команды заранее разрешают чтение, поиск и расчёты. Вопрос ИИ-юристу
> (`ask_yriist`) и всё, что меняет ваши данные (загрузить файл, создать или
> поправить документ, сохранить срок, поставить дело на мониторинг, удалить
> что-либо), Claude Code подтверждает у вас обычным запросом разрешения.
> Платная проверка контрагента `company_check` тоже спрашивает разрешение.
> Кнопки «Готово» и «Вернуть» в панели меняют срок сразу: вы нажимаете их
> сами.

### Файлы с вашего компьютера

Claude Code сам читает текст и PDF с текстовым слоем. DOCX, DOC, RTF и сканы
он отправляет в ЮрИИст: `file_upload_begin` выдаёт ссылку, `curl` загружает по
ней файл, `file_upload_finish` возвращает `file_id`, и `file_read` отдаёт
текст. Файл остаётся в ваших «Файлах» ЮрИИста (или в деле) и занимает место
по тарифу. Загрузку и вызов `curl` Claude Code подтверждает у вас.

### Интерфейс Claude Code

Плагин добавляет в Claude Code:

- **строку состояния** с тарифом, использованием и горящими сроками:

  ```
  ЮрИИст · Профи · использовано 63% · сроков ≤3 дн.: 1
  ```

  На тарифе с лимитом сообщений строка показывает остаток:
  `ЮрИИст · Бесплатный · 4 сообщения`.

- **полосу над полем ввода**, когда срок просрочен или наступает в ближайшие
  3 дня. «Скрыть» убирает её до следующего срочного срока:

  ```
  ЮрИИст · срок через 2 дня: Апелляционная жалоба (12.11.2026)   [Сроки] [Скрыть]
  ```

- **панель `/yriist-panel`**: аккаунт, сроки с кнопками «Готово» и «Вернуть»,
  последние чаты (клик подтягивает чат в разговор), «Спросить ИИ-юриста»;
- **подпись под вызовом инструмента**: «ЮрИИст · Судебная практика».

Плагин перечитывает аккаунт и сроки раз в час через кэш, общий для всех
сессий Claude Code, а чаты только при открытой панели.

### Настройки

`/config` → плагин **yriist** (или при включении плагина):

| Настройка | По умолчанию |
| --- | --- |
| Строка состояния | вкл. |
| Полоса срочных сроков | вкл. |
| Срок «близко», дней | 3 |
| Обновлять раз в, минут | 60 |

Плагин поднимает предел вызова ЮрИИста до 300 секунд (`timeout` в
`.mcp.json`). Без этого Claude Code обрывает долгий ответ `ask_yriist` через
60 секунд.

## Права

При входе ЮрИИст спрашивает, что разрешить. Отозвать доступ можно в
[Аккаунт → Подключения](https://app.yriist.ru/account/connections).

| Право | Инструменты |
| --- | --- |
| `yriist:research` | практика, нормы, контрагенты, расчёты, поиск и чтение в интернете, `anonymize` |
| `yriist:read` | `whoami` и чтение: чаты, «Дела», файлы (`file_read`), документы (`document_export`), шаблоны, сроки, судебные дела, табличный анализ, `memory_list`, `memory_search` |
| `yriist:write` | создание, изменение и удаление: `project_*`, `file_upload*`, `document_*`, `deadline_*`, `case_*`, `review_table_create`, `memory_save`, `memory_delete`, `chat_delete` |
| `yriist:agent` | `ask_yriist` (расходует сообщение тарифа), `chat_stop` |

## Если что-то не так

| Симптом | Что сделать |
| --- | --- |
| Строка состояния «ЮрИИст: войдите — /mcp» | `/mcp` → yriist → Authenticate |
| Панель: «Сервер yriist выключен» | включите сервер в `/mcp` |
| Панель: «ЮрИИст недоступен» | проверьте сеть; состояние сервера смотрите в `/mcp` |
| Токен в файле, а сервер просит войти | токен удалён или истёк: создайте новый или удалите файл и войдите через OAuth |
| Нет `ask_yriist` или действий | вы не выдали право при входе: отключите приложение в «Подключениях» и войдите снова |
| `/yriist:ask` оборвался | ответ доготовится на сервере: панель → «Последние чаты» или «найди мой последний чат ЮрИИста» |
| `curl` не загружает файл | песочница или прокси закрыли доступ к хранилищу: загрузите файл в приложении ЮрИИста и найдите его `/yriist:file` |
| Строка состояния мешает в других проектах | `/config` → yriist → «Строка состояния» выкл. |
| После смены способа входа сервер не подключается | перезапустите Claude Code |
