# Файлы в ЮрИИсте

Загруженный файл ложится в «Файлы» пользователя в ЮрИИсте (с `project_id` в дело) и занимает место хранилища по тарифу. Перед загрузкой назови пользователю файл и место, куда он попадёт. Запись Claude Code подтвердит у пользователя.

Файл уже мог быть загружен раньше: проверь `files_list` по имени. Нашёл: бери его `file_id` и не загружай заново.

## Загрузка через терминал

В Claude Code загружай так: файл любого размера (до лимита тарифа, не больше 300 МБ) уходит в хранилище напрямую и не проходит через разговор.

1. Узнай размер в байтах и SHA-256:
   ```bash
   wc -c < "путь/к/файлу"
   shasum -a 256 "путь/к/файлу"    # в Linux можно sha256sum
   ```
   В Windows (PowerShell): `(Get-Item "файл").Length` и `(Get-FileHash "файл" -Algorithm SHA256).Hash`.
2. Вызови `file_upload_begin` с `name` (имя с расширением: «Договор поставки.pdf»), `size`, `sha256` и `project_id`, если файл для дела.
3. В ответе придут `uploadUrl`, `contentType` и `upload_id`. `deduplicated: true` значит, что такой файл уже лежит в хранилище: переходи к шагу 4. Иначе отправь файл:
   ```bash
   curl -sS --fail -X PUT -H "Content-Type: <contentType>" --upload-file "путь/к/файлу" "<uploadUrl>"
   ```
   Ссылка действует час. Не показывай её в ответе и не записывай в файлы.
4. `file_upload_finish` с `upload_id` вернёт `file_id`. Повторный вызов с тем же `upload_id` вернёт тот же файл.

curl не достучался до хранилища (песочница Claude Code закрыла сеть, прокси): скажи пользователю, какой адрес надо открыть, или предложи загрузить файл в приложении ЮрИИста и найти его `files_list`.

## Маленький файл без терминала

`file_upload` принимает файл целиком в `content_base64` (до 2,5 МБ). Весь base64 проходит через разговор и тратит токены, поэтому бери этот путь, только если терминал недоступен, а файл меньше 50 КБ. Base64 получи командой `base64 < "файл"` (в Linux `base64 -w0 "файл"`).

## Чтение

- `file_read` с `file_id` вернёт текст: PDF со страницами «стр. N», DOCX, DOC, RTF, таблицы, распознанные сканы и фото.
- Скан распознаётся дольше. `status: processing`: вызови `file_read` с тем же `file_id` ещё раз через полминуты, занявшись пока другой частью задачи.
- Длинный текст приходит частями: продолжай с `from_char` из ответа (`nextChar`).

## Что дальше

- Вопрос ИИ-юристу по файлу: `ask_yriist` с `file_ids` (до 10 файлов), расходует сообщение тарифа.
- Нормы в тексте: `check_norms` с текстом из `file_read`.
- Персональные данные: `anonymize` с `file_id`.
- Таблица по многим файлам: `review_table_create` с `file_ids`.
