# Как помочь

Плагин — это тексты команд, агентов и навыков, конфиг MCP-сервера и модуль
интерфейса Claude Code. Сам сервер (инструменты, ответы ИИ-юриста) закрыт:
вопросы о качестве ответов — на support@yriist.ru, не сюда. Уязвимости — по
[SECURITY.md](SECURITY.md).

## Проверка изменений

```sh
sh tests/mcp-headers.test.sh     # скрипт заголовков
claude plugin validate .         # манифест, hooks-модуль, контракт состояния
claude plugin test .             # тесты hooks/register.test.tsx
claude --plugin-dir .            # запустить плагин из папки
```

Типы для редактора (`.claude-plugin/types/`) Claude Code пишет сам, когда
загружает плагин из папки (`--plugin-dir`); после этого `tsc -p .` проверяет
`hooks/` и `types/`. В репозиторий они не попадают.

Локальный или тестовый сервер: `YRIIST_MCP_URL=http://localhost:3000/api/mcp`.

## Правила

- Команды заранее разрешают (`allowed-tools`) только чтение и расчёты.
  Инструменты, которые что-то меняют у пользователя, в этот список не входят.
- Имена инструментов и параметры в текстах должны совпадать с `tools/list`
  сервера: сверяйтесь с [docs/tools.md](https://github.com/Yriist/yriist-mcp/blob/main/docs/tools.md).
- Панель рисует только то, что вернул сервер: без данных — сообщение об
  ошибке, а не пустые списки.
- Тексты для пользователя — на русском; бренд пишется «ЮрИИст».
- На изменение поведения модуля — тест в `hooks/register.test.tsx`, строка в
  `CHANGELOG.md`.

Присылая изменение, вы соглашаетесь на его публикацию под лицензией MIT.
