# Безопасность

Редакция от 10.11.2026.

Об уязвимости сообщите приватно: GitHub → Security → **Report a
vulnerability** в этом репозитории, или письмом на **support@yriist.ru** с
темой «Security». Не создавайте публичный issue, пока уязвимость не закрыта.

## Что делает плагин с вашими данными

- Вход — OAuth в Claude Code (`/mcp` → yriist → Authenticate): токены хранит
  сам Claude Code, плагин их не видит.
- Режим токена: `scripts/mcp-headers.sh` читает личный токен из
  `~/.config/yriist/token` и отдаёт его Claude Code только как заголовок
  `Authorization` для сервера ЮрИИста. Строка, не похожая на токен
  (`yrp_…` из букв и цифр), не отправляется.
- Модуль интерфейса (`hooks/register.tsx`) обращается только к MCP-серверу
  ЮрИИста через соединение Claude Code: читает аккаунт, сроки и список чатов,
  по кнопке «Готово» отмечает срок выполненным. Файлов и сети он не трогает.
- Команды заранее разрешают только инструменты чтения и расчёта. Действия
  (сохранить срок, создать документ, поставить дело на мониторинг) Claude Code
  подтверждает у вас обычным запросом разрешения. Исключение — `/yriist:ask`:
  вы сами задаёте вопрос, и он расходует сообщение тарифа.

Отозвать доступ: [Аккаунт → Подключения](https://app.yriist.ru/account/connections).
